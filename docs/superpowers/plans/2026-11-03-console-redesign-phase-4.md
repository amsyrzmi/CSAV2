# Console Redesign Phase 4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Split Business management and the knowledge page into rail sub-pages (with People & HR as a third rail group), make both pages simple for non-technical people while every detail stays reachable, rename "Knowledge base" to "Business knowledge", restyle the HR screens and the dock onto the shell tokens, run the owner-approved labelling round, and finish with the droppable HR ideas 2 to 5.

**Architecture:** `lib/navigation.ts` gains optional `children` on a nav entry (static for Business and Business knowledge, injected at run time for HR from `lib/hr-paths.ts` via a client hook), rendered by one `NavGroup` row in the rail and the mobile menu. Each sub-page is a literal route folder whose three-line server wrapper passes a `section` prop to the existing workspace component; a shared `SectionNav` bar, a two-level details pattern with a page-wide "Show technical details" switch, and summary tiles live in `components/console/kit/`. No new backend endpoint; the one backend text change is `TAB_LABELS["knowledge_base"]`.

**Tech Stack:** Next.js 16.3.8 (read `WEB/node_modules/next/dist/docs/` before touching routes, layouts or `useSearchParams`), React 19, Tailwind 4, `lucide-react`, node `--test`, Playwright (python) stubbed-upstream browser tests.

**Spec:** `docs/superpowers/specs/2026-11-03-console-redesign-phase-4-design.md` (binding; read sections 3 to 8 before any task). Earlier binding specs: `2026-11-02-console-redesign-phase-3-design.md`, `2026-10-30-console-redesign-phase-2b-design.md`, `2026-10-29-console-redesign-phase-2-design.md`.

- `entryForPath(links: NavLink[], path: string): NavLink | null`: the top-level entry whose href or any child href equals `path`; else the longest top-level href (never `/` or `/portal`) with `path.startsWith(href + "/")`.

Child links call `onNavigate`.
- Rail: when expanded and `link.children?.length`, render `NavGroup`; collapsed renders today's icon link unchanged (no chevron, no children). Open state: `useState<Record<string, boolean>>({})` overrides; `open = overrides[key] ?? currentChild(children, path, href) !== null || path === href`; when `path` changes into a group, drop that group's override. No cookie.
