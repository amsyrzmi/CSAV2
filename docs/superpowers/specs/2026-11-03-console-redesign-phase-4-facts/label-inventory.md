# Console label inventory: plain-language review

Scope: web console `CSA_WebConsole/csa-console/web` on branch `feat/console-redesign-phase-2` (worktree HEAD b787fbf), plus the backend strings it shows. Read-only audit, 2026-11-03. The Malay catalogue was not reviewed. Rows note where a Malay string would also need to change.

How to read the table:
- `{...}` is a value filled in at runtime. ` / ` joins related strings that should be renamed together, so one row can cover several strings.
- "Where" is relative to the web app root. Rows marked `(BACKEND)` are relative to the repo root.
- "Tests" comes from a plain substring search of `tests/**` (Python and snapshot files) and `web/tests/*.mjs`. Keys of 12 characters or fewer were matched only in quotes, as `"x"`, `'x'` or `>x<`. A hit means renaming will probably break that test. A few hits are docstrings or comments (for example `tests/test_business_browser.py:1`), so open the line before editing. "none" means no test contains the string. "n/a" means the text is assembled at runtime, so there is no fixed string to search for.
- Within each screen, rows are roughly ordered most-confusing first. Confidence is about whether the proposed wording is right, not whether the problem is real.
- The brief named "Fine-tune" and a visible `people.sensitive`, but neither appears in the web app. `people.sensitive` is only a backend key (`csa/hr/models.py:108`). The UI shows it as the "Sensitive details" switch (row in the HR section).
